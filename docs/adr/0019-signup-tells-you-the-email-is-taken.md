# 0019. サインアップは「既に登録済み」を伝える（列挙を受け入れる）

**状態**: 採用

## 背景

`(auth)/actions.ts` は Supabase Auth のエラーを `err(error.message)` で
そのまま返していた。実際に返る文言を確かめた。

| 操作                       | 返っていた文言                                |
| -------------------------- | --------------------------------------------- |
| 既存メールでサインアップ   | `User already registered`                     |
| 短いパスワード             | `Password should be at least 6 characters.`   |
| 存在しないメールでログイン | `Invalid login credentials`（変換済みだった） |

問題は2つある。

**日本語 UI に英語が出る。** それ自体もだが、`6 characters` は Supabase 側の
制約で、こちらの Zod は8文字以上を求めている。**画面の案内より緩い内部の数字**が
漏れており、利用者は矛盾した案内を受ける。

**「既に登録済み」はアカウントの存在を明かす。** 誰でもメールアドレスを入れて
「この人はこのサービスに登録しているか」を確かめられる（列挙）。
人材管理 SaaS なので、在籍の推測に使われうる。

## 決定

**エラーは `code` を見て日本語に写像する**（`src/lib/auth-errors.ts`）。
対応表に無いものは内部の文言を出さず、汎用の文言に落とす。

**そのうえで `user_already_exists` は伝える。** 「このメールアドレスは既に
登録されています」と出す。列挙できることは受け入れる。

## 理由

### なぜ列挙を受け入れるのか

隠す場合の選択肢は2つしかなく、どちらも取れない。

- **「登録できませんでした」で理由を伏せる。** 利用者は原因が分からず、
  パスワードが悪いのかメールが悪いのか判断できない。実質サインアップできない
- **成功したふりをしてメールで伝える。** これが本来の定石だが、
  [ADR 0007](./0007-keep-email-confirmation-disabled.md) でメール確認を
  有効化していない。送る経路が無い

**列挙を防ぐ意味も薄い。** ログイン画面は誰でも開けるので、そもそも
「このサービスに登録があるか」はサインアップ以外でも推測されうる。
守りたいのは「誰が在籍しているか」であって、そちらは認可
（[認可マトリクス](../database/authorization-matrix.md)）で守っている。

隠す実装は利用者の不便と引き換えに、防げていない気分だけを得ることになる。

### なぜ `weak_password` はこちらの数字に合わせるのか

Supabase の6文字は内部の制約で、UI の契約は Zod の8文字。
利用者に見せるのは UI の契約であるべきで、内部の数字を見せる理由は無い。

## 捨てた案

| 案                                         | 却下理由                                                 |
| ------------------------------------------ | -------------------------------------------------------- |
| `error.message` をそのまま出す             | 英語が出るうえ、内部の制約が漏れる                       |
| 既存メールでも成功を返し、メールで知らせる | メール確認を有効化していない（ADR 0007）。送る経路が無い |
| 「登録できませんでした」で理由を伏せる     | 原因が分からず、利用者がサインアップを完了できない       |
| メッセージを文字列で分岐する（`===` 比較） | 文言が変わると壊れる。`code` は安定した識別子            |

## 影響

対応表に無いエラーは汎用の文言に落ちる。**新しい `code` が増えたときは
対応表に足すこと。** 落ちること自体は安全側だが、利用者には理由が伝わらない。
