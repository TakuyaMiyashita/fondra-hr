# 画面一覧

各フェーズで画面を実装する際に、状態定義を追記する。

## 凡例

各画面で以下の状態を定義する：

- **通常**: データが存在する場合の表示
- **ローディング**: データ取得中の Skeleton 表示
- **空状態**: データが0件の場合（アイコン + 説明 + CTA）
- **エラー**: データ取得失敗時の表示

| 画面 | パス | 状態定義 |
|------|------|----------|
| ログイン | `/login` | 通常: メール/パスワード入力フォーム。登録完了メッセージ（`?registered=true`）。送信中: ボタン disabled + Loader。エラー: toast |
| サインアップ | `/signup` | 通常: 組織名/メール/パスワード入力フォーム。送信中: ボタン disabled + Loader。エラー: toast |
| パスワードリセット | `/reset-password` | 通常: メール入力フォーム。送信完了: 成功メッセージ表示。送信中: ボタン disabled + Loader。エラー: toast |
| 招待承認 | `/invite/[token]` | 通常: 組織名・ロール表示 + パスワード入力。無効な招待: エラーメッセージ表示。送信中: ボタン disabled + Loader |

| ダークモード切替 | ライト/ダーク/システムの3択ドロップダウン |

## 従業員管理（Phase 3-1）

| 画面 | パス | 状態定義 |
|------|------|----------|
| 従業員一覧 | `/employees` | 通常: DataTable（社員番号/氏名/メール/部署/役職/ステータス/入社日）+ ページネーション + ソート + 検索（300ms デバウンス）+ ステータスフィルタ + 部署フィルタ + CSV エクスポート + カラム表示切替。ローディング: テーブル形状 Skeleton。空状態: Users アイコン + 「従業員が登録されていません」+ 説明。エラー: エラーメッセージ + 再試行ボタン |
| 従業員詳細 | `/employees/[id]` | 通常: ヘッダー（アバター/氏名/社員番号/ステータス Badge/編集・削除ボタン）+ Tabs（基本情報/スキル/1on1/評価）。基本情報: 2カラム dl/grid。各タブ: TanStack Query で遅延取得。ローディング: Skeleton。404: not-found 画面。エラー: エラーメッセージ + 戻るリンク |
| 従業員作成 | Sheet（右開き） | React Hook Form + zodResolver。フィールド: 社員番号(必須)/氏名(必須)/フリガナ/メール/部署(Select)/役職/入社日/生年月日/ステータス(Select)。送信中: ボタン disabled + Loader。成功: toast + Sheet 閉じ + 一覧再取得。エラー: toast / インラインバリデーション |
| 従業員編集 | Sheet（右開き） | 作成と同じ Sheet を edit モードで使用。既存値をデフォルトとして表示。更新成功時: toast + 詳細・一覧を revalidate |
| 従業員削除 | Dialog | 確認ダイアログ（従業員名を表示）。Destructive ボタン。成功: toast + 一覧へ遷移 |
| アバター | 詳細画面内 | クリックでファイル選択。2MB 制限、image/jpeg,png,webp のみ。プレビュー表示。アップロード Server Action は未実装（TODO） |

## 組織図（Phase 3-2）

| 画面 | パス | 状態定義 |
|------|------|----------|
| 組織図 | `/departments` | 通常: ツリー表示（再帰コンポーネント）。各ノード: 部署名 + 所属人数 Badge + アクションメニュー（子部署追加/編集/削除）。展開・折りたたみ（depth < 2 はデフォルト展開）。ローディング: ツリー形状 Skeleton。空状態: Building2 アイコン + 「部署がまだ登録されていません」+ CTA。エラー: エラーメッセージ + 再試行ボタン |
| 部署作成 | Dialog | React Hook Form + zodResolver。フィールド: 部署名(必須)/親部署(Select、なし=トップレベル)。送信中: ボタン disabled + Loader。成功: toast + Dialog 閉じ + router.refresh()。エラー: toast / インラインバリデーション |
| 部署編集 | Dialog | 作成と同じ Dialog を edit モードで使用。編集時は自身と子孫を親部署候補から除外（循環参照防止）。親部署変更時は Service 側でも子孫チェック |
| 部署削除 | Dialog | 確認ダイアログ（部署名を表示）。子部署・所属従業員がある場合は Service 側でエラー返却。Destructive ボタン。成功: toast + ツリー再取得 |

## スキル管理（Phase 3-3）

| 画面 | パス | 状態定義 |
|------|------|----------|
| スキル管理 | `/skills` | 通常: Tabs（スキル一覧/スキルマトリクス）。ローディング: テーブル形状 Skeleton。エラー: エラーメッセージ + 再試行ボタン |
| スキル一覧（タブ） | `/skills` (list tab) | 通常: テーブル（スキル名/カテゴリ Badge/割当人数/操作メニュー）+ 検索（300ms デバウンス）+ カテゴリフィルタ。空状態: Sparkles アイコン + 「スキルが登録されていません」+ CTA。操作メニュー: 編集/削除 |
| スキルマトリクス（タブ） | `/skills` (matrix tab) | 通常: クロス集計グリッド（行=従業員、列=スキル、セル=レベル 1-5 色付きバッジ）。フィルタ: 部署/カテゴリ/従業員名検索。左列固定（sticky）。セルクリック→Popover でレベル変更（1-5）+ 割当解除。空状態: 従業員0件/スキル0件で異なるメッセージ |
| スキル作成 | Dialog | React Hook Form + zodResolver。フィールド: スキル名(必須)/カテゴリ(任意)。送信中: ボタン disabled + Loader。成功: toast + Dialog 閉じ + 一覧再取得。エラー: toast / インラインバリデーション |
| スキル編集 | Dialog | 作成と同じ Dialog を edit モードで使用。既存値をデフォルトとして表示 |
| スキル削除 | Dialog | 確認ダイアログ（スキル名を表示）。従業員に割り当て済みの場合は Service 側でエラー返却。Destructive ボタン。成功: toast + 一覧再取得 |

## 評価（Phase 3-5）

| 画面 | パス | 状態定義 |
|------|------|----------|
| 評価サイクル一覧 | `/evaluations` | 通常: カードリスト（サイクル名/ステータス Badge/期間/評価件数）。クリックで詳細ビュー遷移。ローディング: Skeleton。空状態: ClipboardList アイコン + 「評価サイクルがまだ作成されていません」+ CTA。エラー: エラーメッセージ + 再試行ボタン |
| 評価サイクル詳細 | `/evaluations` (detail view) | 通常: サイクル情報ヘッダー + 評価一覧カード（従業員名/社員番号/ステータス Badge/評価者/平均スコア/コメント抜粋）。空状態: 「まだ評価が追加されていません」+ CTA |
| 評価サイクル作成 | Dialog | React Hook Form + zodResolver。フィールド: サイクル名(必須)/開始日(date,必須)/終了日(date,必須)。送信中: ボタン disabled + Loader。成功: toast + Dialog 閉じ + 一覧再取得。エラー: toast / インラインバリデーション |
| 評価サイクル編集 | Dialog | 作成と同じ Dialog を edit モードで使用。ステータス変更（下書き/進行中/完了）も可能 |
| 評価サイクル削除 | Dialog | 確認ダイアログ（サイクル名を表示）。評価が紐づいている場合は Service 側でエラー返却。Destructive ボタン |
| 評価追加 | Dialog | 対象従業員(Select,必須)/評価者(Select,必須)。重複チェックは Service 側 |
| 評価入力 | Dialog | 評価項目（業績/能力/態度）の 1-5 ボタン入力 + コメント(Textarea) + ステータス変更(Select)。保存時: toast + 一覧再取得 |
| 評価削除 | Dialog | 確認ダイアログ（従業員名を表示）。Destructive ボタン |
